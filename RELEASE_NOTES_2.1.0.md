# Niba Energía 2.1.0

- Amplía el cálculo de factura a contratos con otros códigos de producto, siempre que los precios se hayan validado.
- Admite precios de energía iguales en punta, llano y valle.
- Conserva la protección para evitar importes no fundamentados cuando falten datos.
- Corrige los metadatos de estado del sensor de consumo estimado.

El cálculo de facturas es orientativo; puede diferir de la factura definitiva.
Si encuentras diferencias, abre una incidencia en GitHub sin adjuntar credenciales, CUPS completos ni documentos con datos personales.
